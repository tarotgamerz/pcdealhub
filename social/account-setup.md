# PCDealHub Social Account Setup

## Account order

1. Instagram Business/Creator account
2. Telegram channel + posting bot
3. Facebook Page
4. YouTube channel

Recommended public brand name: PCDealHub
Recommended handle: pcdealhub

## Connection state

The publishing integrations have been initiated through the connected-app system, but no account is treated as active until the platform authentication is completed and verified.

## After connection

Instagram:
- verify the authenticated Business/Creator account
- publish the launch post
- publish one verified deal
- retain the returned permalink

Telegram:
- verify the bot identity
- verify the target channel and administrator permissions
- publish the launch announcement
- retain the channel/message identifiers

Facebook:
- select the managed Page
- verify Page permissions
- publish the launch announcement
- retain the post identifier

YouTube:
- verify the authenticated channel
- publish the first launch video/Short once a media asset is ready
- create a PCDealHub deals playlist

## Cross-posting policy

Use the same factual deal data across platforms, but adapt the presentation to each platform. Never create urgency or price claims that are not supported by the current PCDealHub feed.
