What you are buying

The Ryzen 5 5500 is a 6-core, 12-thread AM4 desktop processor. The current retailer specifications list a 3.6 GHz base clock, up to 4.2 GHz boost, 65W default TDP, DDR4 memory support up to 3200 MT/s, and no integrated graphics. The boxed retail listing includes the AMD Wraith Stealth cooler and a 3-year warranty.

Check the motherboard first

The 5500 uses the AM4 socket and is listed with support for B550, B450, B350, A520 and other compatible chipsets. Compatibility is not just about the socket: an older board may need an appropriate BIOS version. Check your motherboard's CPU support list and BIOS notes before purchasing.

Remember the GPU requirement

The Ryzen 5 5500 has no integrated graphics. A display-capable discrete GPU is therefore required for a normal gaming desktop using this processor. Do not build a 5500 system expecting the motherboard's HDMI or DisplayPort output to work by itself.

Who is it suited to?

It can make sense for a budget AM4 build where the motherboard and DDR4 memory are already available or inexpensive. Pair the CPU with a GPU that fits the total build budget and intended resolution rather than spending most of the budget on one component.

What to compare before checkout

  • CPU + motherboard total cost, not CPU price alone.
  • Whether your board needs a BIOS update.
  • RAM capacity and speed for the games and apps you actually use.
  • GPU, PSU and case costs as part of the complete build.
  • Final checkout price, shipping, returns and warranty terms.
