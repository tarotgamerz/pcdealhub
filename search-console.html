Google Search Console setup

This is the account-owner step that helps Google discover and troubleshoot the site. PCDealHub already has robots.txt and an XML sitemap ready.

1. Add the site property

Open Google Search Console and add the exact site address:

https://tarotgamerz.github.io/pcdealhub/

Complete Google's ownership verification for the property.

2. Submit the sitemap

In Search Console, open Sitemaps and submit:

https://tarotgamerz.github.io/pcdealhub/sitemap.xml

Google says a sitemap is the preferred approach when you have many new or updated pages rather than requesting indexing one page at a time.

3. Inspect priority URLs

Use URL Inspection for the homepage, deals page, major category hubs and your strongest guides. Run Test live URL first; when the page is eligible, use Request indexing.

4. Watch the index coverage

After Google begins crawling, use the Page indexing report to see which URLs were discovered, indexed or excluded. Fix exclusion reasons instead of submitting the same URL repeatedly.

Important: Search Console can request a crawl, but indexing and search appearance are not guaranteed. The site still needs accessible pages, useful original content and Google's normal quality checks.
