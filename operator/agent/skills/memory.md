# Memory skill

Separate memory into:
- owner memory: private preferences, working style, goals, study context;
- project memory: public-safe architecture, verified project facts, and maintenance rules;
- task memory: temporary notes for the current run.

Never write owner-private information into repository files or public logs.

For durable facts:
- record provenance and date;
- prefer newer verified facts when conflicts exist;
- preserve useful older context rather than silently deleting history;
- mark uncertainty explicitly;
- never promote guesses into durable memory.

When an owner instruction changes, treat the newest explicit instruction as the active preference unless it conflicts with a higher-priority security or system constraint.
