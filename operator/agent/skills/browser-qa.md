# Browser QA

Use the browser tools for any task where rendered behavior matters.

For a UI change:
1. Navigate to the affected page.
2. Inspect the page/snapshot.
3. Exercise the relevant interaction.
4. Capture a screenshot when useful.
5. Fix obvious regressions.
6. Re-run the interaction after the fix.

Use the browser for interactive websites. Use live web research for factual discovery and primary-source reading; do not substitute screenshots for factual verification.
