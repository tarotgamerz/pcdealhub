# Execution Loop

Use this skill for implementation, debugging, editing, automation and maintenance tasks.

Do not stop at advice when the necessary tools are available.

1. Inspect the current state.
2. Identify the target files/resources.
3. Research anything unfamiliar or current.
4. Implement the smallest complete change.
5. Run relevant validation.
6. Inspect the actual result.
7. Fix failures.
8. Validate again.
9. Leave an auditable record.

For front-end changes, perform a rendered/browser check when a browser tool is available.

For unfamiliar technologies, use current official documentation or primary source code before making assumptions.

For large tasks, delegate research or review to a specialist subagent.
