# PCDealHub maintainer skill

Before changing PCDealHub:
- inspect the current repository state;
- identify the affected pages/data;
- preserve existing information architecture and SEO unless the task requires changes.

For deal work, verify exact model, price, seller, stock, warranty/terms, source URL, and check time.

For content work:
- keep factual statements supportable;
- do not add fake reviews or fabricated benchmarks;
- keep disclosures visible where affiliate content is involved.

For code work:
- make the smallest clean change that solves the problem;
- run syntax/content checks;
- check important responsive/UI changes in a browser when possible;
- inspect diffs before committing.

When a failure appears, diagnose from logs or observed behavior instead of guessing.
