# PCDealHub Operations

Repository: `tarotgamerz/pcdealhub`
Public site: `https://tarotgamerz.github.io/pcdealhub/`

PCDealHub is a static GitHub-based site with a verified deal feed, buying guides, deal hubs, build planner, RSS, sitemap, robots file and GitHub workflows.

## Deal standard

Only add a listing when the exact model/SKU, live price, current availability, seller and relevant purchase terms are clear.

Prefer clean cross-retailer comparisons for reference prices.

Reject suspicious, stale, ambiguous or weakly verified listings.

Never fabricate affiliate links or relationships. Never modify a retailer URL into a fake tracking link.

Deal scores are internal PCDealHub deal-data signals, not benchmark or product-quality ratings.

## Deployment

Before a consequential deploy:
- inspect the diff,
- run validation,
- check affected links/pages,
- confirm the intended branch/environment,
- obtain approval for the final consequential publish when required.
