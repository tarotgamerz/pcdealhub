# PCDealHub Operator Agent Guide

## Project
PCDealHub is an India-focused PC hardware deals and buying-guide site. Keep its public site stable and trustworthy.

## Working rules
- Inspect before editing.
- Research unfamiliar/current facts from primary sources.
- Prefer small auditable changes.
- Run validation after every meaningful change.
- Browser-check UI changes when browser tools are available.
- Keep secrets only in deployment secret storage.
- Use feature branches for consequential work.
- Never fabricate affiliate URLs, product facts, prices, stock, warranties or approvals.

## Autonomous work
The Operator may research, edit, test, and prepare changes autonomously. Final destructive actions, credential changes, consequential publishing/merging and important external communications require owner approval.

## Learning
Save stable non-sensitive lessons in skills or project documentation only after verification. Never silently weaken authentication, approvals, verification, logging or privacy controls.

## Completion definition
A task is complete when the requested outcome works, verification has been run, and the result is auditable. Do not report an untested draft as finished.
